# Learn the field-chirality experiment

Given three unknown local magnetic fields, decide the sign of their ordered scalar triple product using spin controls with no calibrated axis. The experiment compares two runs that use the same singlet source and detector. A single exchange SWAP changes sides of the exposure window. The frequency difference reveals the field order, and the detector's rare events determine the cost of learning it.

1. Start with the [Bartlett–Rudolph–Spekkens bridge](BARTLETT_RUDOLPH_SPEKKENS_BRIDGE.md). It selects the parts of one review that explain collective rotation invariance, spin multiplicity, and singlet pairing. It also works through two field triads and their detector probabilities.
2. Use the [30-milestone map](MILESTONES.md) to connect those ideas to the three-spin obstruction, the four-spin experiment, and the optimal short-exposure rate.
3. For exact statements and proofs, start at the [science index](../science/README.md).

The learning route takes one simultaneous exposure as the main experiment. The [two-exposure comparison](../science/two-exposures.md) makes clear which resource changes if spin routing is allowed inside the sensing sequence.
